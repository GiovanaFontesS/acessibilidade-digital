#  Contraste de Cores


O contraste de cores é um dos principais fatores para garantir a legibilidade de um conteúdo. Ele consiste na diferença entre as cores do texto e do plano de fundo, permitindo que as informações sejam facilmente visualizadas por pessoas com baixa visão, daltonismo ou outras dificuldades visuais.

Além disso, as cores não devem ser utilizadas como o único meio para transmitir informações importantes. Sempre que uma cor indicar um estado, como erro, sucesso ou alerta, ela deve ser acompanhada por textos, ícones ou outros elementos visuais que garantam a compreensão por todos os usuários.

As Diretrizes de Acessibilidade para Conteúdo Web (WCAG) recomendam uma taxa mínima de contraste de **4,5:1** para textos comuns e **3:1** para textos grandes, contribuindo para uma melhor experiência de leitura e acessibilidade.
